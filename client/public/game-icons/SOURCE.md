# Game icon source

These icon files were downloaded from the rendered asset inventory at
<https://forestshuffle.app/define-forest> on 2026-08-12. Filenames were
normalized for local use. The cave image was resized from 1024 px to 256 px to
avoid shipping an unnecessarily large UI asset; the other images are unchanged.

Before redistributing or publishing the project, confirm that your intended use
complies with the source site's terms and the Forest Shuffle rights holder's
requirements.
